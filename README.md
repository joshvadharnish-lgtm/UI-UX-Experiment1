# UI-UX-Experiment1

## Aim:
To understand the fundamentals of User Interface (UI) and User Experience (UX), distinguish between them using real-world examples, study their relationship in the design process, and explore various UI/UX design tools used for creating user-friendly digital products.
## Algorithm:
1. Study the basic concepts of UI (User Interface) and UX (User Experience).
2. Identify the differences between UI and UX by analysing real-world applications such as Amazon, Instagram, or Google Maps.
3. Observe how UI and UX work together to provide an effective and satisfying user experience.
4. Explore popular UI/UX design tools such as Figma, Adobe XD, Sketch, Invision, Canva, and Balsamiq.
5. Create a simple wireframe or prototype using any one of the design tools.
6. Analyse the design based on usability, accessibility, consistency, and user satisfaction.
7. Document the observations and summarize the learning outcomes.
